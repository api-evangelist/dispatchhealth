# DispatchHealth

> DispatchHealth delivers complex medical care in the home — same-day urgent care, hospital-alternative (hospital-at-home) care, and transitional/recovery care — across roughly 50 US metropolitan areas in partnership with nearly 40 health systems and national payers. Founded in 2013 in Denver, Colorado, it merged with Medically Home in June 2025. Its CESIA platform handles care planning, dispatching, routing, scheduling and real-time patient connectivity, and integrates with a partner health system's existing EMR. DispatchHealth publishes no public developer portal, API documentation, or OpenAPI contract; the only machine-readable surface found on its hosts is an OAuth-protected MCP server exposed by its WordPress marketing site.

- [OAuth authorization server metadata](https://www.dispatchhealth.com/.well-known/oauth-authorization-server): RFC 8414 — authorization_code + refresh_token, PKCE S256, scope `mcp`
- [OAuth protected resource metadata](https://www.dispatchhealth.com/.well-known/oauth-protected-resource): RFC 9728 — protects the MCP endpoint
- [MCP server](https://www.dispatchhealth.com/wp-json/mcp/mcp-oauth-server): JSON-RPC MCP endpoint; `tools/list` returns 401 without an OAuth bearer

- No OpenAPI, Swagger, GraphQL, AsyncAPI, or A2A agent card is published on any DispatchHealth host.
- `api.dispatchhealth.com` answers HTTP 204 with an empty body to every anonymous path.
